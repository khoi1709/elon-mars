A first attempt exited 1 because 900 ms of real W movement produced only 2.5731 world units, below the 3.5-unit audio cue threshold; the bounded retry held W longer, observed 4.60755 units and passed. That first attempt is a harness duration issue, not evidence of a product defect.

- **Local pack:** observed real `GET /mission-data/pack-v2.json` HTTP 200, once per page initialization; validated five expected region IDs. Content completion preceded Lake start and cinematic skip. Canvas rendered at 1280×800; title and world PNG captured.
- **Fallback:** a separate fresh browser profile intercepted only the local pack request and returned 503. The UI showed “Using bundled mission content: local pack request failed (503).”, still offered all five regions, and allowed Lake start. A subsequent reload retained the valid saved mission unchanged. Two pack attempts were observed over the two page loads.
- **Audio:** native Web Audio instrumentation observed a real context resume (`1`), running context, and one oscillator start after trusted canvas click plus public W movement above the selector threshold. The visible pause settings mute checkbox persisted `settings.muted=true`; additional real W input while muted started no new oscillator. This is lifecycle evidence, not a claim that a person heard or judged audio. No independent unmute/replay or hidden-tab lifecycle browser test was performed here; existing audio-controller tests cover their respective controller cases.
- **Rover Help/exit:** public Lake rover control exposed `Help rover`; at 390×844 its button box was 115.36×48.09 px and within the viewport. Clicking Help in the naturally safe rover pose was a no-op (0 displacement), preserving active rover, Leo, stock, evidence, transactions, and support IDs; repeating it remained idempotent. No stuck-pose injection was used, so a successful recovery from a naturally stuck pose was not exercised in the browser (bounded recovery is covered by the dedicated unit test). Public “Return to Leo” restored the exact pose captured just before rover entry; station stock and evidence were unchanged. Full mobile hit-target/overlap interaction was not measured.
- **Reload/render:** after save reload, the canvas continued rendering and actual W movement changed Leo by 2.3256 units. PNG screenshots show positive scene renders with Leo, rover, habitat/terrain and HUD; the fallback/reload frames visually match the fallback run. No page errors were reported. The two expected HTTP 503 console messages in fallback are the adversarial input response.
