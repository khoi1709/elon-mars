# ZIP pilot provenance

This pilot uses only original, locally authored presentation code and existing project code. No source, prose, SVG, media, icon, font, package, or other asset was copied from either reference ZIP; the archive contents were not executed or extracted. The clean-modules reference has no general source-license grant, so its implementation and bundled assets were not transplanted.

The optional impact-practice panel reuses the repository's existing typed impact-matching rules and source-cited science note. The panel's training records, waveforms, and terrain schematics are authored examples, not NASA measurements. Existing NASA links remain factual references and do not imply NASA endorsement.

The scene horizon is a small original inline SVG in the existing field guide. Readiness means only that the running renderer's first post-created frame was observed; it is not a report of complete asset loading, warm-up, or frame rate. Start exploring remains available in every readiness state.
